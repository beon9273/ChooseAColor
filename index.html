Who's playing?

How to play

  • Take turns picking one of the 100 squares. Its hidden number, anywhere from −1,000 to +1,000, is added to your score.
  • Every board hides a 5-square Cheat Path that adds up to exactly 1,000, so the game can always be won.
  • Cheat Code (500 pts): reveals the next square on the Cheat Path. The path only works if you start it at 0 points, so look for the button that zeroes out your score.
  • A square you pick is locked for the next 3 turns. Squares that aren't on the path get a new number when they unlock.
  • Extra Roll (25 pts): spin the wheel to win extra turns.
  • Everyone gets 25 turns. If nobody hits 1,000 by then, whoever is closest wins. Extra turns from the wheel don't count toward the 25.

Special squares

  • 💀Lose It All Your score drops to 0.
  • 🎁Gift Wrap All your points go to another player.
  • 🔄Switcheroo Swap scores with another player.
  • 🍬Treat Code Every square shows its number for 3 seconds, then you pick again.
